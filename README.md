# rules

Готові набори й правила читання сторінок для двигуна, який читає сайти за
описом, а не за кодом.

**Каталог наборів — [КАТАЛОГ.md](КАТАЛОГ.md).** Там перелік із адресами: що
який набір приносить і на які домени просить доступ.

Правило описує ОДИН сайт: за якою адресою його впізнати і звідки на сторінці
брати назву, постер, рік, номер серії й решту полів. Набір — це комплект за
одним посиланням: сторінка-бібліотека, кілька правил, довідник рейтингів,
налаштування.

Усе тут — **дані, а не програми**: набір адрес, селекторів і простих виразів.
Двигун, який їх виконує, живе на боці користувача; тут лежать самі описи, і
двигун робить рівно те, що є в його переліку вмінь.

## Що тут лежить

| Тека | Що всередині |
|---|---|
| `plugins/` | готові набори: бібліотеки й довідники рейтингів |
| `rules/` | окремі правила сайтів, по файлу на домен |
| `rules/ФОРМАТ.md` | опис формату: правило, набір, довідник |

## Як цим користуватись

1. Скопіювати адресу набору з [КАТАЛОГ.md](КАТАЛОГ.md).
2. Вставити її у себе: розділ «Плагіни» в налаштуваннях двигуна.
3. Дозволити доступ до названих доменів — питається в момент підключення,
   одним списком, і перед тим видно, що всередині.

Нічого не встановлюється в систему, файл лишається у вашому браузері.
Вимикач ховає тільки візуал; видалення прибирає й дозволи.

## Як додати своє

Правило — файл у `rules/`, назва це домен сайту (`example.com.json`). Набір —
файл у `plugins/`. Опис формату — `rules/ФОРМАТ.md`. Pull request вітається;
чужі файли ніхто не перевіряє за вас — дивіться, що підключаєте.
