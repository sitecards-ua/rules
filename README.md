# rules

Файли правил читання сторінок. Кожен файл описує ОДИН сайт: за якою адресою
його впізнати і звідки на сторінці брати назву, постер, рік, номер серії
й решту полів.

Правило — це **дані, а не програма**: набір адрес, селекторів і простих
виразів. Двигун, який його виконує, живе на боці користувача; тут лежать
самі описи.

## Як цим користуватись

1. Скачати файл потрібного сайту з теки `rules/`.
2. Підключити його у себе (розділ «Плагіни» в налаштуваннях двигуна).
3. Дозволити двигуну доступ до того домену — питається в момент підключення.

Нічого не встановлюється в систему, файл лишається у вашому браузері.

## Як додати своє правило

Створіть файл у `rules/`, назва — домен сайту (`example.com.json`). Опис
формату — у `rules/ФОРМАТ.md`. Pull request вітається; чужі правила ніхто
не перевіряє за вас — дивіться, що підключаєте.

## Ліцензія

MIT, файл `LICENSE`. Правила описують ПУБЛІЧНУ розмітку сайтів і не містять
ні вмісту цих сайтів, ні способів його обходу.
