# Формат файла правила

Правило — це **опис, а не програма**. Файл `.json`, у якому сказано, за якою
адресою впізнати сайт і звідки на сторінці брати кожне поле. Двигун читає цей
опис і виконує його сам.

Файл ніколи не містить JavaScript, і двигун ніколи його не виконує. Усе, що
може статись від підключення чужого правила — двигун прочитає не ті шматки
сторінки. Він не може ні відкрити нову адресу, крім описаної в `запити`, ні
дістатись до інших сайтів, ні до ваших даних.

Версія формату: **1**. Файл із більшим номером версії двигун не підключить і
скаже, що треба оновитись.

---

## 1. Скелет файла

```json
{
  "версія": 1,
  "сайт": {
    "ключ": "example",
    "назва": "Example",
    "домени": ["example.com", "example.net"],
    "перевірено": "2026-08-31"
  },
  "сторінка": {
    "тільки-у-вкладці": false,
    "заголовок-про-відкрите": true,
    "обрізати-адресу": "/(watch|player|episode)\\b.*$",
    "ключ-картки": { "спосіб": "шлях", "прибрати-розширення": true }
  },
  "поля": { },
  "запити": [ ],
  "пошук": { }
}
```

- **`ключ`** — внутрішнє ім'я сайту. Від домену не залежить: дзеркала того
  самого сайту мають один ключ, інакше та сама сторінка ляже в бібліотеку двічі.
- **`домени`** — за чим сайт упізнається. Свої дзеркала користувач дописує
  сам у налаштуваннях; правило їх не перелічує.
- **`тільки-у-вкладці`** — сайт не віддає сторінку звичайним запитом (403 для
  всіх, хто не браузер). Такі сайти читаються лише у відкритій вкладці.
- **`заголовок-про-відкрите`** — чи заголовок вкладки говорить про ВІДКРИТУ
  серію. У багатьох сайтів він говорить про найсвіжішу; тоді `false`, і номер
  із заголовка не рахується переглядом.

## 2. Значення: вирази

Значення поля — або один крок, або список кроків, який виконується згори вниз
(перше, що дало результат, і виграє).

### Джерела

| Крок | Що робить |
|---|---|
| `{"вузол": "h1"}` | текст першого вузла за селектором |
| `{"вузол": "img.cover", "атрибут": ["src", "data-src"]}` | перший непорожній атрибут із переліку |
| `{"мета": "og:title"}` | мета-тег (`property`, `name`, `og:`, `twitter:` — усі варіанти). Картинку двигун сам добудовує до повної адреси |
| `{"посилання": "canonical"}` | `link[rel=…]` |
| `{"адреса": "-((?:19\|20)\\d{2})\\.html?$"}` | вираз по адресі сторінки |
| `{"текст": "(\\d{1,2})\\s*сезон"}` | вираз по всьому тексту сторінки |
| `{"json-ld": "image"}` | поле з JSON-LD (шукається по всьому графу) |
| `{"підпис": ["рік виходу", "рік"]}` | значення поруч із підписом — див. §4 |
| `{"плеєр": "dle"}` | вбудований розбір плеєра — див. §4 |
| `{"запит": "оригінал"}` | результат додаткового запиту — див. §6 |

### Обробка

Будь-який крок може мати:

- `"витяг": "(\\d+)"` — лишити те, що в дужках;
- `"чистка": "назва"` — іменована нормалізація (перелік нижче);
- `"число": true` — перетворити на число;
- `"обрізати": 160` — обмежити довжину;
- `"збіг": {"фільм": "movie", "серіал": "series"}` — замінити за словником;
- `"не якщо": "(\\d{1,2})\\s*-\\s*(\\d{1,2})\\s*сезон"` — відмовитись від
  значення, якщо вираз збігся (захист від діапазонів і від чужих рядків).

Іменовані чистки: `назва` (зняти хвости сайту, «дивитись онлайн», «N серія»),
`простий` (стиснути пробіли), `сирий` (нічого не робити), `до-скісної`,
`у-лапках`, `латиниця-після-скісної`, `до-коми`, `кома-в-крапку`, `десятий`
(округлити до 0.1).

### Комбінатори

```json
"рік": [
  {"підпис": ["рік виходу", "рік"], "витяг": "((?:19|20)\\d{2})", "число": true},
  {"адреса": "-((?:19|20)\\d{2})\\.html?$", "число": true}
]
```

- **`{"усі": "…", "витяг": "…", "взяти": "найбільше"}`** — зібрати всі вузли за
  селектором і взяти найбільше (або `найменше`, `перше`, `список`).
- **`{"будь-що-з": [ … ]}`** — правда, якщо спрацював хоч один крок (для полів
  типу «це аніме»).

## 3. Поля

```json
"поля": {
  "назва":      [ … ],
  "оригінал":   [ … ],
  "постер":     [ … ],
  "рік":        [ … ],
  "тип":        [ … ],
  "сезон":      [ … ],
  "доступно":   [ … ],
  "всього":     [ … ],
  "серія":      [ … ],
  "озвучка":    [ … ],
  "озвучки":    [ … ],
  "наступна":   [ … ]
}
```

Значення полів різні за призначенням, і плутати їх не можна:

- **`серія`** — та, яку людина ДИВИЛАСЬ. Доказом є позначена серія в списку
  або номер в адресі. Число, написане на сторінці («вийшло 8 серій»), доказом
  не є ніколи.
- **`доступно`** — скільки серій уже вийшло у ВИБРАНІЙ озвучці.
- **`всього`** — скільки буде за сезон.
- **`озвучка`** — вибрана; **`озвучки`** — перелік із кількістю серій у кожної.

Поле, якого сайт не показує, просто не описують. Двигун не вигадує: чого
немає, того немає.

## 4. Вбудовані здатності

Деякі речі описати селектором неможливо, тому двигун уміє їх сам, а правило
лише передає параметри.

### `підпис` — значення поруч із підписом

Найчастіший спосіб узагалі. Шукає листовий вузол, чий текст дорівнює підпису,
і бере значення поруч.

```json
{"підпис": ["кількість серій", "серій", "епізоди"],
 "де-значення": "сусід",
 "стоп": ["статус", "жанр"]}
```

`де-значення`: `сусід` (наступний вузол), `комірка` (остання комірка рядка
таблиці), `батько-мінус-підпис` (текст батька без самого підпису). Якщо не
вказано — двигун пробує всі три. `стоп` — підписи, на яких значення
обривається, коли все злиплось в один рядок.

### `плеєр` — блок плеєра

`{"плеєр": "dle"}` читає стандартний плеєр DLE (uakino, anitube і подібні):
режим (озвучення/субтитри), студії, скільки серій у кожної, яка вибрана.
Звідси беруться `озвучки`, `озвучка` і `доступно`.

Серія з плеєра зараховується переглядом лише коли вкладку відкрила людина —
`"вимагає-видимості": true`. Це не налаштування «про людське око», а те, що
відрізняє «я дивився» від «сторінку оновив фон».

### Драбина серій

Як саме двигун вирішує, що людина дивилась, налаштовується не виразом, а
параметрами:

```json
"серія": {"драбина": {
  "позначена": [".episode.active", "li.active"],
  "з-адреси": true,
  "із-заголовка": false
}}
```

Порядок доказів (позначений вузол → адреса → заголовок) двигун не віддає в
дані: це смисл, а не розмітка.

### Інші здатності

- `{"розклад": {"рядки": [".b-post__schedule tr"]}}` — найближча майбутня дата
  виходу, номер серії й назва з того самого рядка. Місяці розуміються
  українською, російською й англійською.
- `{"постер": "каскад"}` — типовий пошук обкладинки: перелік звичних
  селекторів і атрибутів, JSON-LD, фон у стилі; сміття (`data:`, `.svg`,
  `favicon`, `logo`, `placeholder`) відсіюється.
- `{"поділитись": true}` — текст із посилань «поділитись» (там часто лежить
  оригінальна назва, якої в розмітці немає).
- `{"звірка": ["назва:\\s([2-9])$", "-([2-9])-anime"]}` — число зараховується,
  лише коли те саме число є в обох місцях. Проти вгаданих сезонів.

## 5. Ключ картки і дзеркала

```json
"ключ-картки": {"спосіб": "dle-id", "вираз": "/(\\d{1,7})-[^/]*\\.html"}
```

Способи: `шлях` (весь шлях сторінки), `dle-id` (число з адреси), `вираз`
(своя дужка). Ключ має бути однаковим на всіх дзеркалах сайту — на дзеркалі
слаг зазвичай інший, а число те саме.

## 6. Додаткові запити

Іноді потрібного немає в розмітці, і сайт віддає його окремою адресою.

```json
"запити": [{
  "ім'я": "оригінал",
  "коли": "порожнє:оригінал",
  "id-з-адреси": "/(\\d{1,7})-[^/]*\\.html",
  "адреса": "{origin}/engine/ajax/get_orgname.php?id={id}",
  "як": "json",
  "взяти": "nameorg"
}]
```

Запит іде тільки на той самий домен, що й сторінка, і тільки коли поле справді
порожнє. `коли` буває `порожнє:<поле>` або `завжди`.

## 7. Пошук по сайту

```json
"пошук": {
  "адреса": "https://{host}/index.php?do=search&subaction=search&story={q}",
  "як": "html",
  "куки": true,
  "картка": "#dle-content article.story",
  "поля": {
    "адреса": {"вузол": "h2 a", "атрибут": "href"},
    "назва":  {"вузол": "h2 a"},
    "постер": {"вузол": ".story_post img", "атрибут": ["data-src", "src"]},
    "рік":    {"вузол": ".story_c_inf", "витяг": "Рік виходу[^\\d]*(\\d{4})"}
  }
}
```

`куки: true` — деякі сайти без кук віддають сторінку-передпокій замість
результатів.

## 8. Набір (плагін)

Одне правило — це найдрібніший випадок. Звичайний спосіб поділитись — **набір
за одним посиланням**: людина вставляє адресу, і в неї з'являється готова
сторінка з правилами, довідником і налаштуваннями. Файл той самий `.json`, так
само дані, і так само не виконується.

```json
{
  "версія": 1,
  "плагін": {
    "ключ": "serialy-ua",
    "назва": "Серіали й фільми",
    "опис": "Бібліотека серіалів: рік, сезон, кількість серій і чия озвучка.",
    "версія": "1.1",
    "оновлено": "2026-09-02"
  },
  "сторінка": { "назва": "Серіали", "колонок": 4 },
  "правила": [ { …файл правила цілком… } ],
  "довідник": { … },
  "дзеркала": { "uakino": ["uakino.club"] },
  "налаштування": { "мова назв": "uk" }
}
```

- **`ключ`** — за ним набір упізнається при оновленні. Той самий ключ →
  оновлення на місці; сторінка з картками при цьому лишається.
- **`сторінка`** — створюється один раз, при першому підключенні.
- **`правила`** — звичайні файли правил, укладені в масив. Кожне перевіряється
  окремо; биття в одному називається номером і не ламає решту.
- **`дзеркала`** — запасні домени вже відомих сайтів, за ключем сайту.
- **`налаштування`** — тільки `мова назв`, `тема`, `акцент`. Решту двигун
  пропустить і скаже про це.

### Що набір уміє — вичерпний перелік

`сторінка`, `правила`, `довідник`, `дзеркала`, `налаштування`. Це весь
перелік. Незнайомий ключ верхнього рівня не помилка — двигун його пропустить і
покаже попередження. **Тому чужий набір не може принести нової поведінки:**
він лише вибирає з готового.

### Дозволи

Двигун збирає всі домени набору (з правил, з довідника, з дзеркал) і питає їх
**одним списком, в одну мить, у відповідь на натискання**. Перед цим він
показує, що всередині: скільки правил, який довідник, які домени. Вимикач у
списку плагінів ховає тільки візуал — сторінка зникає з очей, картки й дозволи
лишаються. Видалення прибирає все: сторінку, картки, правила й дозволи.

## 9. Довідник

Сайт перегляду знає, скільки вийшло серій. Він не знає, наскільки тайтл
хороший. Це вміє довідник — зовнішня база (Shikimori, TMDB тощо), яка дає
оцінку, оригінальну назву, рік і чистий постер.

```json
"довідник": {
  "назва": "TMDB",
  "домени": ["api.themoviedb.org", "image.tmdb.org"],
  "для": ["series", "movie"],
  "ключ-потрібен": true,
  "поле-ключа": "Ключ TMDB (API Key v3)",
  "де-взяти-ключ": "themoviedb.org → Settings → API",
  "пошук": {
    "адреса": "https://api.themoviedb.org/3/search/multi?api_key={ключ}&query={q}",
    "як": "json",
    "список": "results",
    "поля": {
      "назва": "name|title",
      "оригінал": "original_name|original_title",
      "рейтинг": "vote_average",
      "рік": "first_air_date|release_date",
      "постер": "poster_path",
      "id": "id"
    },
    "префікс-постера": "https://image.tmdb.org/t/p/w500",
    "шаблон-сторінки": "https://www.themoviedb.org/tv/{id}"
  }
}
```

- **`для`** — типи контенту, за які довідник береться (`anime`, `series`,
  `movie`). Не сказано — береться за будь-який. Аніме-довідник за серіал не
  візьметься й нічого не вигадає.
- **`адреса`** — обов'язково з `{q}` (назва) і, коли потрібен ключ, з
  `{ключ}`. Адреса мусить вести на домен із `домени` цього ж довідника —
  інакше двигун набір не підключить.
- **`список`** — шлях до масиву у відповіді. Немає — відповідь і є масивом.
- **`поля`** — графи відповіді. Крапка — вкладеність (`image.original`),
  риска — рівноцінні варіанти (`name|title`: у TMDB серіал зветься `name`, а
  фільм `title`).
- **`префікс-постера`**, **`база`**, **`шаблон-сторінки`** — добудова
  скорочених адрес до повних.

### Ключ

Ключа у файлі набору **немає й бути не може** — там стоїть тільки місце
`{ключ}`. Свій ключ людина вписує в списку плагінів; він лежить у її
налаштуваннях і їде тільки в цей самий запит.

### Як вибирається тайтл

Порівнюються спрощені назви, а рік служить розв'язкою: однойменних серіалів
вистачає. Якщо схожого немає зовсім — картка лишається без оцінки. Підписати
її чужим числом гірше, ніж не підписати нічим.

## 10. Чого двигун не робить ніколи

- Не виконує код із файла правила.
- Не ходить на домени, яких немає в `домени` цього правила або довідника
  (додаткові запити — теж тільки туди).
- Не питає дозволу на домен наперед: дозвіл питається в момент, коли ви
  підключаєте правило, і його видно в налаштуваннях.
- Не надсилає нікуди ні сторінок, ні вашої бібліотеки.

## 11. Сумісність

Номер `версія` міняється тільки тоді, коли старі файли перестають читатись.
Нові необов'язкові поля номер не міняють: двигун ігнорує те, чого не знає, і
каже про це в налаштуваннях, а не мовчки.
