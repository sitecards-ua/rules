# Каталог наборів

Набір — це готовий комплект за одним посиланням: сторінка-бібліотека, правила
читання сайтів, довідник рейтингів, налаштування. Скопіюйте адресу набору й
вставте її в двигуні: **⚙ → «Плагіни» → поле адреси → «+ Додати плагін»**.

Перед підключенням вам покажуть, що всередині — скільки правил, який довідник
і на які домени потрібен доступ. Дозвіл питається один раз, одним списком, у
момент вашого натискання. Вимикач у списку ховає тільки візуал: сторінка
зникає з очей, а картки й дозволи лишаються. Видалення прибирає плагін, а його
сторінку кладе в кошик — картки звідти повертаються.

**Набори оновлюються самі.** Раз на добу двигун звіряється з тією ж адресою і
тихо забирає нову версію — без вікон і без питань. Виняток один: якщо нова
версія просить доступ до сайтів, яких ще не дозволено, вона чекає на ваше
натискання в списку плагінів, а поки що працює попередня.

Файли — це **дані, а не програми**. Двигун їх не виконує: він робить рівно те,
що є в його переліку вмінь (`сторінка`, `правила`, `довідник`, `дзеркала`,
`налаштування`), і нічого понад це. Опис формату — [rules/ФОРМАТ.md](rules/ФОРМАТ.md).

## Почати з одного посилання

Якщо не хочеться розбиратись, який набір за що відповідає — є один, що несе
все одразу: сторінку «Бібліотека», чотири сайти й рейтинг без ключа.

```
https://raw.githubusercontent.com/sitecards-ua/rules/main/plugins/vse.json
```

| | |
|---|---|
| Приносить | сторінка «Бібліотека» · 4 правила сайтів · довідник «TMDB» · дзеркала |
| Сайти | UAKino, UASerials, HDrezka, AnimeLib |
| Ключ | не потрібен |

**HDrezka й AnimeLib читаються лише з увімкненим читачем** — вимикач там же,
⚙ → «Плагіни» → «Читач у відкритій вкладці». Решта двох сайтів працює без нього.

Далі — те саме, але окремими наборами, якщо потрібен не весь комплект.

## Довідники рейтингів

Довідник не читає сайти перегляду — він знає про тайтл те, чого ті не пишуть:
оцінку, оригінальну назву, рік, чистий постер. Своєї сторінки не створює:
працює на тих картках, які у вас уже є.

### Рейтинг аніме — Shikimori

Ключ не потрібен. Береться тільки за аніме.

```
https://raw.githubusercontent.com/sitecards-ua/rules/main/plugins/shikimori.json
```

| | |
|---|---|
| Приносить | довідник «Shikimori» |
| Доступ до | `shikimori.one` |
| Ключ | не потрібен |

пошуку, далі сторінка тайтла — звідти точна оцінка, обкладинка, оригінальна
назва і стан релізу.

## Окремі правила

Якщо потрібен один сайт, а не цілий набір — файл правила підключається тим
самим полем. Сторінки він не створює, тільки вчить читати цей сайт.

| Сайт | Адреса файла | |
|---|---|---|
| AniTube | `https://raw.githubusercontent.com/sitecards-ua/rules/main/rules/anitube.in.ua.json` | |
| UAKino | `https://raw.githubusercontent.com/sitecards-ua/rules/main/rules/uakino.best.json` | |
| UASerials | `https://raw.githubusercontent.com/sitecards-ua/rules/main/rules/uaserials.com.json` | |
| HDrezka | `https://raw.githubusercontent.com/sitecards-ua/rules/main/rules/hdrezka.co.json` | **потрібен читач** |
| AnimeLib | `https://raw.githubusercontent.com/sitecards-ua/rules/main/rules/animelib.org.json` | **потрібен читач** |

HDrezka не віддає сторінку звичайним запитом, тому це правило працює лише з
увімкненим читачем (див. розділ вище). Домен у файлі один — `hdrezka.co`, той,
що працював на 04.09.2026; сайт їх міняє, свій дописується в налаштуваннях
сайту, а не правкою файла.

AnimeLib у сирій розмітці порожній — усе домальовує скрипт, тому без читача
сторінка не читається взагалі. Класи на сайті обфусковані й міняються з кожною
його збіркою, тому правило їх не торкається: усе взято з JSON-LD і з підписів
у таблиці («Эпизоды», «Выпуск»). Бере назву, оригінальну назву латиницею,
обкладинку, рік, жанр, тривалість серії та «21 з 24» окремими числами.

Що воно бере: назву, оригінальну назву, обкладинку, рік, тип, відкритий сезон,
скільки серій у ньому вийшло і перелік озвучок. **Серії рахуються з відкритого
сезону**, а не «найбільше число на сторінці»: у розмітці лежать списки всіх
сезонів одразу, і без цієї обережності третій сезон показував би кількість
серій першого.

## Сайти, які читаються вкладкою

Деякі сайти не віддають сторінку звичайним запитом: одні відповідають 403
усьому, що не схоже на браузер, інші малюють сторінку скриптом, і в сирій
розмітці немає нічого. Для таких у розширенні є **читач у відкритій вкладці**:
він відкриває сторінку окремою вкладкою у фоні, забирає з неї готову розмітку
й одразу вкладку закриває.

Читач вимкнений, поки ви самі його не увімкнете: **⚙ → «Плагіни» → «Читач у
відкритій вкладці»**. Це окремий дозвіл браузера, і розширення ставиться без
нього — хто таких сайтів не дивиться, той його й не дає.

Працює він **тільки з вашого натискання** — «Оновити» на картці або в шапці
бібліотеки. Фонове оновлення такі сайти мовчки пропускає: вкладка, що
відкрилась сама, поки ви зайняті іншим, — не те, що розширення має право
робити з вашим браузером.

У правилі сайту це вмикається одним рядком — `"тільки-у-вкладці": true`
(див. [rules/ФОРМАТ.md](rules/ФОРМАТ.md)).

## Своє правило

Файл кладеться в `rules/`, назва — домен сайту (`example.com.json`); набір — у
`plugins/`. Формат описано в [rules/ФОРМАТ.md](rules/ФОРМАТ.md). Pull request
вітається. Чужі файли ніхто не перевіряє за вас — дивіться, що підключаєте:
адреси доменів і перелік того, що набір приносить, видно перед підключенням.
